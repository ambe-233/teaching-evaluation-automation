# 教学评教自动化脚本

Windows 电脑版工具：微信里打开教学质量管理平台的每周评教，跑脚本按配额自动分配 A/B/C 等级，逐门填答卷并提交。支持 Windows 计划任务每周定时运行。本机实测跑通 18 门课。

## 适用环境

- 只支持 Windows 电脑版 + 微信电脑版内置浏览器
- - Mac / Linux / 手机不支持
  - - 屏幕分辨率与 DPI 与开发者一致时开箱即用；不同需按文档调坐标
    - - 页面结构改版需重新适配
     
      - ## 使用前准备
     
      - - 下载下方 评教脚本包.zip 并解压到任意目录
        - - 双击 安装依赖.bat 安装 pywinauto / numpy / Pillow
          - - 微信里打开评教页（会话中的问卷链接 → 查看详情），停在「选择教师课程等级」页
           
            - ## 使用流程
           
            - ### 一键全流程（推荐）
           
            - ```bash
              python run.py all
              ```

              选等级 → 自动提交 → 逐门答卷，全程无人值守。

              ### 分步运行（先按当周配额改脚本里的 plan）

              ```bash
              python batch.py       # 批量选等级
              python batch2.py      # 若上面点不准用这个动态定位版
              python answer_all.py  # 逐门答卷，从提交成功弹窗点下一门开始
              ```

              ### 每周定时运行（Windows 计划任务）

              ```cmd
              schtasks /Create /TN "评教自动化" /TR ""C:\你的路径\python.exe" "C:\路径\run.py" all" /SC WEEKLY /D FRI /ST 18:00 /F
              ```

              - 每周五 18:00 自动运行；改时间改 /ST，改星期改 /D
              - - 运行前需手动把微信评教页开好，脚本只操作已打开的窗口
                - - 计划任务里必须写绝对路径的 Python 解释器，不能只写 python
                 
                  - ## 填写规则
                 
                  - - 分数区间判级：[90,100]=A、[70,90)=B、[0,70)=C（A=100分，B=80分，C=60分）
                    - - 选 A/C 触发理由必填：A 勾教学态度，C 勾教学效果，B 不勾
                      - - 意见框留空
                        - - 各等级可选人数由系统限定，超额提交不了
                         
                          - ## 注意
                         
                          - - 提交后一般不可修改，先小范围验证再全量跑
