# 教学评教自动化脚本

Windows 电脑版工具：微信里打开教学质量管理平台的每周评教，跑脚本按配额自动分配 A/B/C 等级，逐门填答卷并提交。本机实测跑通 18 门课。

## 适用环境

• 只支持 Windows 电脑版 + 微信电脑版内置浏览器
• Mac / Linux / 手机不支持
• 屏幕分辨率与 DPI 与开发者一致时开箱即用；不同需按文档调坐标
• 页面结构改版需重新适配

## 使用前准备

• 下载下方 评教脚本包.zip 并解压到任意目录
• 双击 安装依赖.bat 安装 pywinauto / numpy / Pillow
• 微信里打开评教页（会话中的问卷链接 → 查看详情）

## 使用流程

先按当周页面显示的配额改脚本里的 plan，再按顺序运行：

python batch.py       批量选等级
python batch2.py      若上面点不准用这个动态定位版
python answer_all.py  逐门答卷，从提交成功弹窗点下一门开始

## 填写规则

• 分数区间判级：[90,100]=A、[70,90)=B、[0,70)=C（A=100分，B=80分，C=60分）
• 选 A/C 触发理由必填：A 勾教学态度，C 勾教学效果，B 不勾
• 意见框留空
• 各等级可选人数由系统限定，超额提交不了

## 注意

• 提交后一般不可修改，先小范围验证再全量跑
• 详细文档、换环境适配方法、常见问题见 zip 内 README.md
• 学校视角可能视为批量刷评教，使用责任自负
